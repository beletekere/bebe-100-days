# אתגר 100 הימים 🔥

אפליקציית מעקב אישית לאתגר: בלי אלכוהול, בלי עישון, ריצה (יעד: יום כן יום לא, נמדדת בדקות, כל יום פתוח לסימון), תרגילי שחרור גוף, שינה לפני חצות, שתיית לפחות 1 ליטר מים ביום. כולל תיעוד ויזואלי (תמונות/סרטונים), גלריית התקדמות, גרפים, ציוני דרך, השוואה שבועית, השוואת "לפני מול אחרי", ואפשרות לחזור ולערוך ימים קודמים שכבר נשמרו (דרך כפתור "ערוך יום זה" במסך "יומן").

האפליקציה בנויה כאתר סטטי (HTML/CSS/JS) ללא צורך בשרת. הצ'קליסט, מצב הרוח ופרטי הריצה יכולים להסתנכרן חינם בין הפלאפון למחשב דרך Firebase. **תמונות וסרטונים נשמרים תמיד רק על המכשיר שצילם אותם** (כדי להימנע לגמרי מהזנת כרטיס אשראי).

## הרצה מקומית (בדיקה במחשב)

צריך שרת מקומי קטן (לא ניתן פשוט לפתוח את index.html כקובץ, כי הדפדפן חוסם חלק מהתכונות בפרוטוקול file://):

```bash
npx serve .
```

ואז פותחים את הכתובת שתופיע (בדרך כלל http://localhost:3000).

## שלב 1 - הפעלת סנכרון בין פלאפון למחשב (חינמי, בלי כרטיס אשראי)

1. גולשים ל-https://console.firebase.google.com ומתחברים עם חשבון Google.
2. "Add project" → בוחרים שם (למשל `bebe-100-days`) → אפשר לכבות Google Analytics (לא נדרש).
3. בתוך הפרויקט: לוחצים על סמל ה-Web (</>) כדי להוסיף אפליקציית Web, נותנים שם, **לא** מסמנים Firebase Hosting.
4. Firebase יציג אובייקט קונפיגורציה כזה - מעתיקים אותו:
   ```js
   const firebaseConfig = {
     apiKey: "...",
     authDomain: "...",
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
5. פותחים את הקובץ [js/firebase-config.js](js/firebase-config.js) בפרויקט ומדביקים את הערכים במקום ה-placeholders.
6. בתפריט הצד: **Build → Firestore Database → Create database** → מצב **Production** → בוחרים מיקום (למשל `eur3`).
7. בלשונית **Rules** מדביקים את הכללים הבאים ולוחצים Publish:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /boxes/{boxId}/{document=**} {
         allow read, write: if true;
       }
     }
   }
   ```
   **הערה על אבטחה:** אין כאן התחברות עם סיסמה - הגישה מוגנת רק בכך שה-"קוד אישי" (boxId) הוא מזהה אקראי וארוך שאי אפשר לנחש. זה מספיק טוב לנתוני הרגלים אישיים, אבל זו לא רמת אבטחה בנקאית - אל תשתמש בזה למידע רגיש יותר.

## שלב 2 - יצירת קוד אישי לסנכרון

1. פותחים את האפליקציה (בפלאפון או במחשב), עוברים ללשונית **"הגדרות"**.
2. לוחצים **"צור קוד חדש"** - יופיע קוד ארוך, מעתיקים אותו.
3. במכשיר השני (השני מבין פלאפון/מחשב), עוברים גם כן ל-"הגדרות" ולוחצים **"הזן קוד קיים"**, מדביקים את הקוד.
4. מעכשיו הצ'קליסט, מצב הרוח ופרטי הריצה מתעדכנים אוטומטית בין שני המכשירים כשיש אינטרנט.

## שלב 3 - גישה מהפלאפון מכל מקום (לא רק בבית)

כדי שהאפליקציה תהיה זמינה מהפלאפון גם כשלא נמצאים ליד המחשב, הכי פשוט זה לארח את הקבצים (הקוד בלבד, לא הנתונים) בחינם ב-GitHub Pages:

1. יוצרים חשבון חינמי ב-https://github.com (אם אין).
2. יוצרים repository חדש **ציבורי** (זה בסדר - הוא מכיל רק קוד, לא את הנתונים האישיים שלך, שנשמרים ב-Firebase ובמכשיר עצמו).
3. מעלים אליו את כל הקבצים מהתיקייה הזו.
4. ב-Settings → Pages בוחרים את הענף (branch) הראשי כמקור, שומרים.
5. אחרי דקה תקבל כתובת כמו `https://<username>.github.io/<repo>/` - זו הכתובת שפותחים בפלאפון (אפשר "הוסף למסך הבית" כדי שתיראה כמו אפליקציה).

## גיבוי מקומי

במסך "הגדרות" יש כפתור **"ייצוא גיבוי"** שמוריד קובץ JSON יחיד עם כל הצ'קליסט, פרטי הריצות והתמונות/סרטונים. כדאי לשמור את הקובץ הזה מדי פעם (Google Drive, מייל לעצמך וכו') - זו לא תחליף לסנכרון Firebase, אלא רשת ביטחון למקרה שמשהו קורה לפלאפון או שמנקים את נתוני הדפדפן. שחזור נעשה עם כפתור **"ייבוא גיבוי"** באותו מסך, בבחירת הקובץ שהורדת.

## מגבלה לגבי תזכורות

בלי שרת אמיתי, אי אפשר לשלוח התראות Push אמיתיות בזמן קבוע (כמו "20:00 כל ערב"). האפליקציה מציגה במקום זאת באנר תזכורת בתוך המסך "היום" אם פותחים אותה בערב ועדיין לא סימנת הכל. מומלץ להוסיף גם תזכורת/אלארם רגיל בפלאפון בשעה קבועה כדי לא לשכוח לפתוח את האפליקציה.

## מבנה הפרויקט

- `index.html` - מסך האפליקציה
- `css/style.css` - עיצוב
- `js/habits.js` - רשימת ההרגלים (כולל ימי הריצה)
- `js/quotes.js` - ציטוטי מוטיבציה יומיים
- `js/store.js` - שמירת צ'קליסט/מצב רוח/ריצה מקומית (localStorage)
- `js/db.js` - שמירת תמונות/סרטונים מקומית (IndexedDB)
- `js/cloud.js` - סנכרון Firestore (אופציונלי)
- `js/firebase-config.js` - הפרטים מ-Firebase (למלא בעצמך)
- `js/backup.js` - ייצוא/ייבוא גיבוי מקומי לקובץ
- `js/app.js` - הלוגיקה של המסכים, כולל ציוני דרך, השוואה שבועית ו"לפני מול אחרי"
